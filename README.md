# YOUR FLOW

**나에게 맞는 요가 자세를 탐색하고, 흐름을 만들어 보는 웹앱**

[웹앱 바로가기](https://yoga-flow-app-sepia.vercel.app/index.html)

## 프로젝트 소개

YOUR FLOW는 요가 아사나(자세)를 살펴보고 원하는 조건에 맞춰 루틴을 구성할 수 있는 웹앱입니다. 자세별 정보를 한눈에 확인할 수 있는 **요가 도감**과 여러 자세를 연결하는 **루틴 빌더**를 중심으로 개발하고 있습니다.

## 주요 기능

### 1. 요가 자세 도감
- 요가 자세 48종을 카드형 갤러리로 탐색
- 한국어·영어·산스크리트어 이름 검색
- 난이도, 자세 유형, 신체 부위, 운동 목표 등 조건별 필터
- 자세별 상세 설명과 이미지·영상 콘텐츠 표시(자료가 준비된 항목에 한함)
- 모바일 화면을 고려한 반응형 레이아웃

### 2. 맞춤형 루틴 빌더
- 조건에 맞는 자세를 조합해 루틴 생성
- 시작 자세는 **연꽃자세**, 마지막 자세는 **송장자세**로 고정
- 시작·마무리 자세는 선택 개수와 순번에서 제외
- 4~12개(짝수)의 본운동 자세 선택을 목표로 구성
- 자세 중복과 연결 흐름을 고려한 루틴 생성 로직 개선 중

> 루틴 생성 조건과 자세 간 연결 알고리즘은 계속 검증·개선 중입니다. 일부 조건 조합에서는 결과가 제한될 수 있습니다.

## 기술 구성

| 구분 | 기술 |
| --- | --- |
| 프론트엔드 | HTML, CSS, JavaScript |
| 데이터 처리 | JSON, Fetch API |
| 데이터베이스 | MySQL |
| 데이터베이스 호스팅 | Railway |
| 배포 | Vercel |
| 버전 관리 | Git, GitHub |

초기 데이터 탐색에는 공개 [Yoga API](https://github.com/alexcumplido/yoga-api)를 참고했습니다. 현재 서비스의 데이터 처리에는 SQL 데이터베이스 연동 작업이 포함되어 있습니다.

## 개발 및 운영 메모

- 프론트엔드 수정 후 GitHub에 커밋·푸시하면 Vercel 배포 설정에 따라 변경 사항이 반영됩니다.
- 데이터베이스 접속 정보 등 비밀값은 `.env` 또는 배포 환경변수로 관리하며 GitHub에 업로드하지 않습니다.
- 데이터베이스를 사용하는 기능은 로컬 정적 파일 실행만으로 정상 동작하지 않을 수 있습니다. 서버 및 환경변수 설정이 필요합니다.
